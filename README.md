# 💍 Luxury Wedding Invitation Website (Next.js)

An elegant, mobile-first luxury wedding invitation web application built with **Next.js**, bespoke Vanilla CSS / CSS Modules, and rich animations.

Designed with a warm **champagne beige, gold foil, pearl white, and velvet charcoal/black** aesthetic.

---

## ✨ Features

- **💌 Interactive 3D Wax Seal Envelope**: Envelope unfolding animation with an embossed golden monogram stamp.
- **🎵 Romantic Music Player**: "Play our favorite song" audio player with animated gold equalizer bars and soothing acoustic arpeggios.
- **⏳ Countdown & Calendar**: Real-time ticking countdown (`Days : Hours : Mins : Secs`) and monthly calendar with an animated golden heart circling the wedding day, plus a 1-click **Add to Google Calendar** button.
- **💒 Ceremony & Reception**: Detailed event cards with interactive Google Maps preview modal and 1-click address copy.
- **📜 Itinerary Timeline**: Vertical dashed gold timeline with custom icons (*Ceremony, Welcome Cocktail, First Dance, Gala Dinner, Party, and Farewell*).
- **👗 Dress Code Guide**: Attire guide for ladies and gentlemen with color palette swatches.
- **🎁 Gift Registry & Bank Info**: Scannable QR code and bank transfer card with 1-click clipboard copy and toast notification.
- **✉️ Interactive RSVP**: Full attendance form with guest count, meal/diet preferences, song request, and a celebratory **gold confetti burst**.
- **🌐 English & Sinhala Bilingual Toggle**: Instant 1-tap switcher between English and Sinhala (`English` / `සිංහල`) with authentic, respectful translations and Noto Serif Sinhala typography.
- **✨ Ambient Gold Sparkles**: Soft floating golden dust particles overlay.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```

---

## ⚙️ Customization

All couple names, wedding dates, venue addresses, itinerary steps, and bank details are centralized in:
👉 `src/data/wedding.js`

Simply update the values in that file to customize for any wedding.
